Projeto: Site para Fábrica de Costura

Tecnologias
- React
- TailwindCSS
- Node.js (futuro backend)
- PostgreSQL (futuro banco)
- Power BI (futuras análises)

Objetivo
Criar um sistema completo contendo:

Front-End
Site institucional responsivo.

Back-End
API para pedidos e cadastro de clientes.

Banco de Dados
Controle de vendas e estoque.

BI
Dashboards para análise de produção e vendas.
